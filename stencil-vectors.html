Stencil Vectors

Stencil Vectors🔗

stencil vector（stencil 向量）类似于 vector，但它带有一个关联的 掩码 fixnum，掩码中置位的位数决定了向量的长度。stencil 向量可用于实现某些数据 结构 [Torosyan21]，例如哈希数组映射前缀树（HAMT）。

从概念上讲，stencil 向量的掩码指示了完整大小的 stencil 向量中哪些虚拟元素是存在的， 但掩码位对通过 stencil-vector-ref 和 stencil-vector-set! 进行的 访问或修改没有影响。例如，这样一个 stencil 向量的掩码为 25，也可以写作 #b11001；从低位到高位读取，该掩码表示第一个、第四个和第五个虚拟 位置存在值。如果该 stencil 向量的元素为 'a、'b 和 'c， 那么 'a 位于虚拟位置 0，使用索引 0 访问；'b 位于虚拟位置 3， 使用索引 1 访问；'c 位于虚拟位置 4，使用索引 2 访问。

掩码中位的相对顺序对于使用 stencil-vector-update 进行的功能性更新操作 是相关的。要移除的元素通过移除掩码指定，要添加的元素通过添加掩码相对于 剩余元素来确定顺序。例如，从掩码为 #b11001、元素为 'a、 'b 和 'c 的 stencil 向量开始，使用添加掩码 #b100100 添加新元素 'd 和 'e，将产生一个掩码为 #b111101、元素依次为 'a、'b、'd、 'c 和 'e 的 stencil 向量。

stencil 向量的最大大小在 64 位平台上为 58 个元素，在 32 位平台上为 26 个元素。 这种有限的大小使得内部表示更加紧凑，并确保更新操作相对简单。stencil 向量是可变的， 但主要设计用于在不变异的情况下实现持久化数据结构。

当两个 stencil 向量具有相同的掩码，且对应位置的值满足 equal? 时，它们是 equal? 的。

打印的向量以 #<stencil ...> 开头，且该打印形式不能被 read 解析。 s-exp->fasl 和 serialize 函数不支持 stencil 向量，部分原因是 64 位平台上的 stencil 向量可能无法在 32 位平台上表示。stencil 向量的用途是作为 数据类型实现的内存中表示。

Added in version 8.5.0.7.

procedure

(stencil-vector? v) → boolean?

  v : any/c
当 v 是 stencil vector 时返回 #t，否则返回 #f。

Examples:
> (stencil-vector #b10010 'a 'b)

#<stencil 18: a b>

> (stencil-vector #b111 'a 'b 'c)

#<stencil 7: a b c>

Added in version 8.5.0.7.

procedure

(stencil-vector-mask-width) → exact-nonnegative-integer?

返回当前平台上 stencil 向量允许的最大元素数量。在 64 位平台上结果为 58， 在 32 位平台上结果为 26。

procedure

(stencil-vector mask v ...) → stencil-vector?

  mask : (integer-in 0 (sub1 (expt 2 (stencil-vector-mask-width))))
  v : any/c
返回一个将 mask 与元素 v 组合在一起的 stencil 向量。 提供的 v 的数量必须与 mask 的二进制补码表示中置位的位数相匹配。

Added in version 8.5.0.7.

procedure

(stencil-vector-mask vec)

 → (integer-in 0 (sub1 (expt 2 (stencil-vector-mask-width))))
  vec : stencil-vector?
返回 vec 的掩码。注意，stencil 向量的掩码在创建时确定，之后无法更改。

Example:
> (stencil-vector-mask (stencil-vector #b10010 'a 'b))

18

Added in version 8.5.0.7.

procedure

(stencil-vector-length vec)

 → (integer-in 0 (sub1 (stencil-vector-mask-width)))
  vec : stencil-vector?
返回 vec 的长度（即向量中的槽数）。结果与 (fxpopcount (stencil-vector-mask vec)) 相同。

Example:
> (stencil-vector-length (stencil-vector #b10010 'a 'b))

2

Added in version 8.5.0.7.

procedure

(stencil-vector-ref vec pos) → any/c

  vec : stencil-vector?
  pos : exact-nonnegative-integer?
返回 vec 中位置 pos 的元素。第一个位置为 0， 最后一个位置为 (stencil-vector-length vec) 减一。

Examples:
> (stencil-vector-ref (stencil-vector #b10010 'a 'b) 1)

'b

> (stencil-vector-ref (stencil-vector #b111 'a 'b 'c) 1)

'b

Added in version 8.5.0.7.

procedure

(stencil-vector-set! vec pos v) → avoid?

  vec : stencil-vector?
  pos : exact-nonnegative-integer?
  v : any/c
将 vec 中位置 pos 的内容更新为 v。

Examples:
> (define st-vec (stencil-vector #b101 'a 'b))
> st-vec

#<stencil 5: a b>

> (stencil-vector-set! st-vec 1 'c)
> st-vec

#<stencil 5: a c>

Added in version 8.5.0.7.

procedure

(stencil-vector-update vec    
  remove-mask    
  add-mask    
  v ...) → stencil-vector?
  vec : stencil-vector?
  remove-mask : (integer-in 0 (sub1 (expt 2 (stencil-vector-mask-width))))
  add-mask : (integer-in 0 (sub1 (expt 2 (stencil-vector-mask-width))))
  v : any/c
返回一个类似于 vec 的 stencil 向量，但移除了与 remove-mask 对应的 元素，并根据 add-mask 在相对于现有（未移除的）元素的位置添加给定的 v。

Examples:
> (define st-vec (stencil-vector #b101 'a 'b))
> (stencil-vector-update st-vec #b0 #b10 'c)

#<stencil 7: a c b>

> (stencil-vector-update st-vec #b0 #b1000 'c)

#<stencil 13: a b c>

> st-vec ; 不因更新而改变

#<stencil 5: a b>

> (stencil-vector-update st-vec #b1 #b1 'c)

#<stencil 5: c b>

> (stencil-vector-update st-vec #b100 #b100 'c)

#<stencil 5: a c>

> (stencil-vector-update st-vec #b100 #b0)

#<stencil 1: a>

Added in version 8.5.0.7.
