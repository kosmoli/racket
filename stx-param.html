语法参数🔗

 (require racket/stxparam) package: base
The bindings documented in this section are provided by the racket/stxparam library, not racket/base or racket.

syntax

(define-syntax-parameter id expr)

将 id 绑定为 syntax 到一个 syntax parameter。 expr 是 transformer environment 中的一个表达式， 作为 syntax parameter 的默认值。该值通常由 transformer 使用 syntax-parameter-value 获得。

id 可以与 syntax-parameterize 或 syntax-parameter-value（在 transformer 中）使用。如果 expr 产生一个单参数的 procedure 或 make-set!-transformer 结果， 则 id 可以用作 macro。如果 expr 产生一个 make-rename-transformer 结果，则 id 可以用作 macro， 展开为对目标标识符的使用，但 syntax-local-value 的 id 不产生目标的值。

syntax

(syntax-parameterize ([id expr] ...) body-expr ...+)

另请参见 splicing-syntax-parameterize。

每个 id 必须绑定到使用 define-syntax-parameter 定义的 syntax parameter。每个 expr 是 transformer environment 中的一个表达式。在展开 body-expr 期间，每个 expr 的值 绑定到相应的 id。

如果 expr 产生一个单参数的 procedure 或 make-set!-transformer 结果， 则在展开 body-expr 期间其 id 可以用作 macro。 如果 expr 产生一个 make-rename-transformer 结果， 则 id 可以用作 macro，展开为对目标标识符的使用， 但 syntax-local-value 的 id 不产生目标的值。

Examples:
> (define-syntax-parameter abort (syntax-rules ()))
> (define-syntax forever
    (syntax-rules ()
      [(forever body ...)
       (call/cc (lambda (abort-k)
         (syntax-parameterize
             ([abort (syntax-rules () [(_) (abort-k)])])
           (let loop () body ... (loop)))))]))
> (define-syntax-parameter it (syntax-rules ()))
> (define-syntax aif
    (syntax-rules ()
      [(aif test then else)
       (let ([t test])
         (syntax-parameterize ([it (syntax-id-rules () [_ t])])
           (if t then else)))]))

syntax

(define-rename-transformer-parameter id expr)

将 id 绑定为 syntax 到一个 syntax parameter， 该参数必须绑定到 make-rename-transformer 结果，并且与 define-syntax-parameter 不同，id 的 syntax-local-value 确实 产生目标的值，包括在 syntax-parameterize 内。

Examples:
> (define-syntax (test stx)
   (syntax-case stx ()
     [(_ t)
      #`#,(syntax-local-value #'t)]))
> (define-syntax one 1)
> (define-syntax two 2)
> (define-syntax-parameter not-num
    (make-rename-transformer #'one))
> (test not-num)

#<procedure:syntax-parameter>

> (define-rename-transformer-parameter num
    (make-rename-transformer #'one))
> (test num)

1

> (syntax-parameterize ([num (make-rename-transformer #'two)])
    (test num))

2

1 Syntax Parameter Inspection🔗

 (require racket/stxparam-exptime) package: base

procedure

(syntax-parameter-value id-stx) → any

  id-stx : syntax?
此过程旨在用于 transformer environment，其中 id-stx 是在普通环境中绑定到 syntax parameter 的标识符。 结果是 syntax parameter 的当前值，经过 syntax-parameterize 形式的调整。

此绑定由 racket/stxparam 提供 for-syntax， 因为它通常在 transformer 中使用。由 racket/stxparam-exptime 正常提供。

procedure

(make-parameter-rename-transformer id-stx) → any

  id-stx : syntax?
此过程旨在用于 transformer 中，其中 id-stx 是绑定到 syntax parameter 的标识符。结果是一个 transformer， 其行为与 id-stx 相同，但不能与 syntax-parameterize 或 syntax-parameter-value 一起使用。

使用 make-parameter-rename-transformer 类似于调用一个调用 parameter 的过程。 这样的过程可以导出给他人以允许访问 parameter 值，但不改变它。类似地， make-parameter-rename-transformer 允许 syntax parameter 用作 macro，但不能更改。

make-parameter-rename-transformer 的结果不会被 syntax-local-value 特殊处理，这与 make-rename-transformer 的结果不同。

此绑定由 racket/stxparam 提供 for-syntax， 因为它通常在 transformer 中使用。由 racket/stxparam-exptime 正常提供。
