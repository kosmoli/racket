Symbols🔗

(part ("(lib scribblings/guide/guide.scrbl)" "symbols")) in (part ("(lib scribblings/guide/guide.scrbl)" "top")) introduces symbols.

一个 symbol 就像一个不可变的 string，但 symbols 通常是 interned，因此具有相同字符内容的两个 symbols 通常是 eq?。 默认 reader（参见 (part "parse-symbol")）产生的所有 symbols 都是 interned。

string->uninterned-symbol 和 gensym 这两个 procedures 生成 uninterned symbols，即不与任何其他 symbol eq?、 eqv? 或 equal? 的 symbols，尽管它们可能与其他 symbols 打印得相同。

string->unreadable-symbol procedure 返回一个 unreadable symbol， 该 symbol 是部分 interned 的。默认 reader（参见 (part "parse-symbol")）从不 产生 unreadable symbol，但对 string->unreadable-symbol 的两次调用 如果使用 equal? 的 strings，会产生 eq? 的结果。 一个 unreadable symbol 可能与 interned 或 uninterned symbol 打印得相同。 Unreadable symbols 在 expansion 和 compilation 中用于避免与源文件中 出现的 symbols 发生冲突；它们通常不会直接生成，但可能出现在 identifier-binding 等函数的结果中。

Interned 和 unreadable symbols 仅由内部 symbol 表 weak 持有。这种弱性永远 不会影响 eq?、eqv? 或 equal? 测试的结果，但当 一个 symbol 被放入 weak box 时（参见 (part "weakbox")），用作 weak hash table 的 key 时（参见 (part "hashtables")），或用作 ephemeron key 时（参见 (part "ephemerons")），可能会消失。

See (part "parse-symbol") for information on reading symbols and (part "print-symbol") for information on printing symbols.

procedure

(symbol? v) → boolean?

  v : any/c
如果 v 是一个 symbol，则返回 #t，否则返回 #f。

Examples:
> (symbol? 'Apple)

#t

> (symbol? 10)

#f

procedure

(symbol-interned? sym) → boolean?

  sym : symbol?
如果 sym 是 interned，则返回 #t，否则返回 #f。

Examples:
> (symbol-interned? 'Apple)

#t

> (symbol-interned? (gensym))

#f

> (symbol-interned? (string->unreadable-symbol "Apple"))

#f

procedure

(symbol-unreadable? sym) → boolean?

  sym : symbol?
如果 sym 是一个 unreadable symbol，则返回 #t，否则返回 #f。

Examples:
> (symbol-unreadable? 'Apple)

#f

> (symbol-unreadable? (gensym))

#f

> (symbol-unreadable? (string->unreadable-symbol "Apple"))

#t

procedure

(symbol->string sym) → string?

  sym : symbol?
返回一个新分配的 mutable string，其字符与 sym 中的字符相同。

另参见 racket/symbol 中的 symbol->immutable-string。

Example:
> (symbol->string 'Apple)

"Apple"

procedure

(string->symbol str) → symbol?

  str : string?
返回一个 interned symbol，其字符与 str 中的字符相同。

Examples:
> (string->symbol "Apple")

'Apple

> (string->symbol "1")

'|1|

procedure

(string->uninterned-symbol str) → symbol?

  str : string?
类似于 (string->symbol str)，但结果是一个新的 uninterned symbol。 用相同的 str 调用 string->uninterned-symbol 两次会返回两个 不同的 symbols。

Examples:
> (string->uninterned-symbol "Apple")

'Apple

> (eq? 'a (string->uninterned-symbol "a"))

#f

> (eq? (string->uninterned-symbol "a")
       (string->uninterned-symbol "a"))

#f

procedure

(string->unreadable-symbol str) → symbol?

  str : string?
类似于 (string->symbol str)，但结果是一个新的 unreadable symbol。 对等效的 strs 调用 string->unreadable-symbol 两次会返回 相同的 symbol，但 read 从不产生该 symbol。

Examples:
> (string->unreadable-symbol "Apple")

'Apple

> (eq? 'a (string->unreadable-symbol "a"))

#f

> (eq? (string->unreadable-symbol "a")
       (string->unreadable-symbol "a"))

#t

procedure

(gensym [base]) → symbol?

  base : (or/c string? symbol?) = "g"
返回一个 具有自动生成名称的新 uninterned symbol。可选的 base 参数 是一个前缀 symbol 或 string。

Example:
> (gensym "apple")

'apple3177

procedure

(symbol<? a-sym b-sym ...) → boolean?

  a-sym : symbol?
  b-sym : symbol?
如果参数按顺序排序则返回 #t，其中每对 symbols 的比较 使用 symbol->string 与 string->bytes/utf-8 和 bytes<? 进行。

Changed in version 7.0.0.13: Allow one argument, in addition to allowing two or more.

procedure

(symbol->immutable-string sym) → (and/c string? immutable?)

  sym : symbol?
类似于 symbol->string，但结果是一个 immutable string， 不一定是新分配的。

Examples:
> (symbol->immutable-string 'Apple)

"Apple"

> (immutable? (symbol->immutable-string 'Apple))

#t

Added in version 7.6 of package base.
