展开顶层形式🔗

procedure

(expand top-level-form [insp]) → syntax?

  top-level-form : any/c
  insp : inspector? = (current-code-inspector)
展开 top-level-form 中所有非原始语法，并返回一个只包含核心形式（符合 (part "fully-expanded") 指定的语法）的 syntax object 的展开结果。

在 top-level-form 被展开之前，其词法上下文通过 namespace-syntax-introduce 进行丰富，如同 eval 中一样。使用 syntax->datum 将返回的 syntax object 转换为可打印的 datum。

如果 insp 不是原始的 code inspector（即 Racket 启动时 (current-code-inspector) 的值），则结果是 tainted syntax object。

在模块上使用 expand 的示例：

(parameterize ([current-namespace (make-base-namespace)])
 (expand
  (datum->syntax
   #f
   '(module foo scheme
      (define a 3)
      (+ a 4)))))

在非顶层形式上使用 expand 的示例：

(define-namespace-anchor anchor)
(parameterize ([current-namespace
                (namespace-anchor->namespace anchor)])
 (expand
  (datum->syntax
   #f
   '(delay (+ 1 2)))))

Changed in version 8.2.0.4: 添加了 insp 参数和 taint 支持。

procedure

(expand-syntax stx [insp]) → syntax?

  stx : syntax?
  insp : inspector? = (current-code-inspector)
类似于 (expand stx insp)，但参数必须是 syntax object， 且其词法上下文在展开前不被丰富。

Changed in version 8.2.0.4: 添加了 insp 参数和 taint 支持。

procedure

(expand-once top-level-form [insp]) → syntax?

  top-level-form : any/c
  insp : inspector? = (current-code-inspector)
部分展开 top-level-form，返回一个用于部分展开表达式的 syntax object。 由于展开机制的局限性，某些上下文信息可能会丢失。特别是对结果调 用 expand-once 可能产生与通过 expand 展开不同的结果。

在 top-level-form 展开之前，其词法上下文通过 namespace-syntax-introduce 丰富，如 eval 中一样。

insp 参数决定结果是否为 tainted，与 expand 相同。

Changed in version 8.2.0.4: 添加了 insp 参数和 taint 支持。

Changed in version 8.2.0.4: 添加了 insp 参数和 taint 支持。

procedure

(expand-to-top-form top-level-form [insp]) → syntax?

  top-level-form : any/c
  insp : inspector? = (current-code-inspector)
部分展开 top-level-form 以显露最外层的语法形式。这种 部分展开主要用于检测顶层 begin 的使用。与 expand-once 的结果不同，使用 expand 展开 expand-to-top-form 的结 果会产生与使用 expand 展开原始语法相同的结果。

在 stx-or-sexpr 展开之前，其词法上下文通过 namespace-syntax-introduce 丰富，如 eval 中一样。

insp 参数决定结果是否为 tainted，与 expand 相同。

Changed in version 8.2.0.4: 添加了 insp 参数和 taint 支持。

1 展开模块的信息🔗

展开的 module 声明信息存储在附加到 syntax object 的一组 syntax properties 中（参见 (part "stxprops")）：

  • 'module-body-context — 一个 syntax object，其 lexical information 对应模块内部，因此包括 展开的 outside-edge scope 和 inside-edge scope； 也就是说，syntax object 模拟一个存在于原始模块主体中、宏无法 访问的标识符，因此其词法信息包括模块导入和定义的绑定。

    Added in version 6.4.0.1.

  • 'module-body-inside-context — 一个 syntax object，其 lexical information 对应一个没有词法上下文 就开始并被移入宏的标识符，因此它仅包括展开的 inside-edge scope。

    Added in version 6.4.0.1.

  • 'module-body-context-simple? — 一个布尔， #t 表示模块主体的绑定（如 'module-body-inside-context 属性的值的 lexical information 中所记录的）可以直接从直接导入模块的模块中重 构，包括导入的 for-syntax、for-meta 和 for-template。

    Added in version 6.4.0.1.

Changed in version 7.0: 移除了 'module-variable-provides、 'module-syntax-provides、 'module-indirect-provides 和 'module-indirect-for-meta-provides 属性。
