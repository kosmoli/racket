用于打包分发的 API

 (require compiler/bundle-dist) package: compiler-lib
compiler/bundle-dist 库提供了一个函数， 用于将目录（通常是由 assemble-distribution 组装的）包装成分发文件。 在 Windows 上，结果是 ".zip" 归档；在 Mac OS 上，是 ".dmg" 磁盘映像；在 Unix 上，是 ".tgz" 归档。

procedure

(bundle-directory dist-file dir [for-exe?]) → void?

  dist-file : file-path?
  dir : file-path?
  for-exe? : any/c = #f
将 dir 打包到 dist-file 中。如果 dist-file 没有扩展名，会自动添加文件扩展名（使用 bundle-put-file-extension+style+filters 的第一个结果）。

创建的归档包含名称与 dir 相同的目录——除非在 Mac OS 上，当 for-exe? 为真且 dir 包含一个单独文件或目录， 在这种情况下，创建的磁盘映像只包含该文件或目录。 for-exe? 的默认值为 #f。

如果 dist-file 存在，归档创建将失败。
