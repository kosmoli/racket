Kernel 形式和函数

 #lang racket/kernel package: base
racket/kernel 库是一个 跨阶段持久模块，提供最小的 syntactic form 和函数集。

"最小"意味着 racket/kernel 仅包含内置于 Racket 编译器中的 form 和内置于运行时系统中的函数。目前，binding 集并不是特别小，也不是定义特别明确， 因为 built-in 函数集可能会频繁更改。谨慎使用 racket/kernel， 并注意其使用可能产生兼容性问题。

racket/kernel 模块导出 fully expanded 程序语法中的所有 binding （参见 (part "fully-expanded")），但它将 #%plain-lambda 作为 lambda 和 λ 提供，#%plain-app 作为 #%app， 以及 #%plain-module-begin 作为 #%module-begin。除了 #%datum（其展开为 quote），racket/kernel 不提供其他 syntactic binding。

racket/kernel 模块还导出 racket/base 中的许多 function binding，并且导出一些未由 racket/base 导出的其他函数， 因为 racket/base 导出了改进的变体。由 racket/kernel 导出的 function binding 的确切集未指定，可能会在不同版本间变化。

 (require racket/kernel/init) package: base
racket/kernel/init 库重新提供所有 racket/kernel 的内容。它还提供 #%top-interaction，这使得 racket/kernel/init 在 racket 的 -I 命令行标志下很有用。
