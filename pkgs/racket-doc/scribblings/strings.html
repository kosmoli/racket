Strings🔗

(part ("(lib scribblings/guide/guide.scrbl)" "strings")) in (part ("(lib scribblings/guide/guide.scrbl)" "top")) introduces strings.

一个 string 是固定长度的 characters 数组。

字符串可以是 可变 的或 不可变 的。如果将不可变的字符串传给类似 string-set! 的过程，将引发 exn:fail:contract exception is raised。默认读取器（见 (part "parse-string")）生成的字符串常量是不可变的，在 read-syntax 模式下会被 驻留。使用 immutable? 检查字符串是否不可变。

两个字符串长度相同且包含相同的字符序列时，它们是 equal? 的。

字符串可以用作单值序列（见 (part "sequences")）。序列的元素就是字符串中的字符。另见 in-string。

See (part "parse-string") for information on reading strings and (part "print-string") for information on printing strings.

另见：immutable?、symbol->string、bytes->string/utf-8。

1 String Constructors, Selectors, and Mutators🔗

procedure

(string? v) → boolean?

  v : any/c
如果 v 是字符串则返回 #t，否则返回 #f。

另见 immutable-string? 和 mutable-string?。

Examples:
> (string? "Apple")

#t

> (string? 'apple)

#f

procedure

(make-string k [char]) → string?

  k : exact-nonnegative-integer?
  char : char? = #\nul
返回一个新的可变字符串，长度为 k，每个位置用字符 char 初始化。

Example:
> (make-string 5 #\z)

"zzzzz"

procedure

(string char ...) → string?

  char : char?
返回一个新的可变字符串，长度等于给定的 char 的数量，各位置用给定的 char 初始化。

Example:
> (string #\A #\p #\p #\l #\e)

"Apple"

procedure

(string->immutable-string str) → (and/c string? immutable?)

  str : string?
返回一个不可变字符串，内容与 str 相同。如果 str 本身不可变，则返回 str 自身。

Examples:
> (immutable? (string #\H #\e #\l #\l #\o))

#f

> (immutable? (string->immutable-string (string #\H #\e #\l #\l #\o)))

#t

procedure

(string-length str) → exact-nonnegative-integer?

  str : string?
返回 str 的长度。

Example:
> (string-length "Apple")

5

procedure

(string-ref str k) → char?

  str : string?
  k : exact-nonnegative-integer?
返回 str 中位置 k 的字符。第一个位置对应 0，所以 k 必须小于字符串的长度，否则引发 exn:fail:contract exception is raised。

Example:
> (string-ref "Apple" 0)

#\A

procedure

(string-set! str k char) → void?

  str : (and/c string? (not/c immutable?))
  k : exact-nonnegative-integer?
  char : char?
将 str 中位置 k 的字符修改为 char。第一个 位置对应 0，所以 k 必须小于字符串的长度，否则 引发 exn:fail:contract exception is raised。

Examples:
> (define s (string #\A #\p #\p #\l #\e))
> (string-set! s 4 #\y)
> s

"Apply"

procedure

(substring str start [end]) → string?

  str : string?
  start : exact-nonnegative-integer?
  end : exact-nonnegative-integer? = (string-length str)
返回一个新的可变字符串，长度为 (- end start) 字符，包含 str 中从 start（含）到 end（不含）的字符。第一个位置对应 0，所以 start 和 end 参数必须小于等于 str 的长度，且 end 必须大于等于 start，否则引发 exn:fail:contract exception is raised。

Examples:
> (substring "Apple" 1 3)

"pp"

> (substring "Apple" 1)

"pple"

procedure

(string-copy str) → string?

  str : string?
返回 (substring str 0)。

Examples:
> (define s1 "Yui")
> (define pilot (string-copy s1))
> (list s1 pilot)

'("Yui" "Yui")

> (for ([i (in-naturals)] [ch '(#\R #\e #\i)])
    (string-set! pilot i ch))
> (list s1 pilot)

'("Yui" "Rei")

procedure

(string-copy! dest    
  dest-start    
  src    
  [src-start    
  src-end]) → void?
  dest : (and/c string? (not/c immutable?))
  dest-start : exact-nonnegative-integer?
  src : string?
  src-start : exact-nonnegative-integer? = 0
  src-end : exact-nonnegative-integer? = (string-length src)
修改 dest 中从位置 dest-start 开始的字符， 使其与 src 中从 src-start（含）到 src-end（不含）的字符一致， 其中第一个位置对应 0。 dest 和 src 可以是同一个字符串， 这种情况下目标区域可以与源区域重叠；复制后目标中的字符与复制前源中的字符一致。如果 dest-start、 src-start 或 src-end 中任何一个超出范围（考虑 字符串的大小以及源和目标区域），将引发 exn:fail:contract exception is raised。

Examples:
> (define s (string #\A #\p #\p #\l #\e))
> (string-copy! s 4 "y")
> (string-copy! s 0 s 3 4)
> s

"lpply"

procedure

(string-fill! dest char) → void?

  dest : (and/c string? (not/c immutable?))
  char : char?
修改 dest，使其中每个位置都用 char 填充。

Examples:
> (define s (string #\A #\p #\p #\l #\e))
> (string-fill! s #\q)
> s

"qqqqq"

procedure

(string-append str ...) → string?

  str : string?
返回 一个新的可变字符串，长度等于所有给定的 str 长度的总和，包含给定的 str 连接后的字符。如果未提供任何 str，结果是一个长度为零的字符串。

Example:
> (string-append "Apple" "Banana")

"AppleBanana"

procedure

(string-append-immutable str ...) → (and/c string? immutable?)

  str : string?
与 string-append 相同，但结果是一个不可变字符串。

Examples:
> (string-append-immutable "Apple" "Banana")

"AppleBanana"

> (immutable? (string-append-immutable "A" "B"))

#t

Added in version 7.5.0.14.

procedure

(string->list str) → (listof char?)

  str : string?
返回一个新的字符列表，对应于 str 的内容。即，列表长度为 (string-length str)，str 中的字符序列与结果列表中的序列相同。

Example:
> (string->list "Apple")

'(#\A #\p #\p #\l #\e)

procedure

(list->string lst) → string?

  lst : (listof char?)
返回一个新的可变字符串，内容为 lst 中的字符列表。即，字符串长度为 (length lst)，lst 中的字符序列与结果字符串中的序列相同。

Example:
> (list->string (list #\A #\p #\p #\l #\e))

"Apple"

procedure

(build-string n proc) → string?

  n : exact-nonnegative-integer?
  proc : (exact-nonnegative-integer? . -> . char?)
通过按顺序将 proc 应用于从 0 到 (sub1 n) 的整数，创建一个包含 n 个字符的字符串。如果 str 是结果字符串，则 (string-ref str i) 是 (proc i) 产生的字符。

Example:
> (build-string 5 (lambda (i) (integer->char (+ i 97))))

"abcde"

3 String Conversions🔗

procedure

(string-upcase str) → string?

  str : string?
返回 将 str 中的字符进行大写转换后的字符串。转换使用 Unicode 的 locale 无关的转换规则，将码点序列映射到码点序列（而不是简单地在字符串上对码点使用一对一函数映射），因此转换产生的字符串可能比输入字符串长。

Examples:
> (string-upcase "abc!")

"ABC!"

> (string-upcase "Stra\\xDFe")

"STRA\\XDFE"

procedure

(string-downcase string) → string?

  string : string?
类似于 string-upcase，但进行小写转换。

Examples:
> (string-downcase "aBC!")

"abc!"

> (string-downcase "Stra\\xDFe")

"stra\\xdfe"

> (string-downcase "\\u039A\\u0391\\u039F\\u03A3")

"\\u039a\\u0391\\u039f\\u03a3"

> (string-downcase "\\u03A3")

"\\u03a3"

procedure

(string-titlecase string) → string?

  string : string?
类似于 string-upcase，但仅对 str 中每个带大小写字符序列的第一个字符进行 titlecase 转换 （忽略 case-ignorable 字符）。

Examples:
> (string-titlecase "aBC  twO")

"Abc  Two"

> (string-titlecase "y2k")

"Y2k"

> (string-titlecase "main stra\\xDFe")

"Main Stra\\Xdfe"

> (string-titlecase "stra \\xDFe")

"Stra \\Xdfe"

procedure

(string-foldcase string) → string?

  string : string?
类似于 string-upcase，但进行 case-folding 转换。

Examples:
> (string-foldcase "aBC!")

"abc!"

> (string-foldcase "Stra\\xDFe")

"stra\\xdfe"

> (string-foldcase "\\u039A\\u0391\\u039F\\u03A3")

"\\u039a\\u0391\\u039f\\u03a3"

procedure

(string-normalize-nfd string) → string?

  string : string?
返回 是 string 的 Unicode normalized form D 的字符串。如果给定的字符串已经处于相应的 Unicode normal form， 字符串可能直接返回作为结果（而不是新分配的字符串）。

Example:
> (equal? (string-normalize-nfd "Ç") "C\\u0327")

#f

(string-normalize-nfkd string) → string?

  string : string?
类似于 string-normalize-nfd，但针对 normalized form KD。

Example:

#t

(string-normalize-nfc string) → string?

  string : string?

Example:

5 String Grapheme Clusters🔗

procedure

(string-grapheme-span str start [end]) → exact-nonnegative-integer?

  str : string?
  start : exact-nonnegative-integer?
  end : exact-nonnegative-integer? = (string-length str)
返回字符串中从 start 开始的 Unicode 簇（假设 start 是簇的起点）所包含的字符（即码点）数量，延伸至 end 前的字符为止。如果 start 等于 end，结果为 0。

start 和 end 参数必须是与 substring 中一样有效的索引，否则引发 exn:fail:contract exception is raised。

另见 char-grapheme-cluster-step。

Examples:
> (string-grapheme-span "" 0)

0

> (string-grapheme-span "a" 0)

1

> (string-grapheme-span "ab" 0)

1

> (string-grapheme-span "\\r\\n" 0)

1

> (string-grapheme-span "\\r\\nx" 0)

1

> (string-grapheme-span "\\r\\nx" 2)

1

> (string-grapheme-span "\\r\\nx" 0 1)

1

Added in version 8.6.0.2.

procedure

(string-grapheme-count str start [end])

 → exact-nonnegative-integer?
  str : string?
  start : exact-nonnegative-integer?
  end : exact-nonnegative-integer? = (string-length str)
返回 (substring str start end) 中的簇数量。

start 和 end 参数必须是与 substring 中一样有效的索引，否则引发 exn:fail:contract exception is raised。

Examples:
> (string-grapheme-count "")

0

> (string-grapheme-count "a")

1

> (string-grapheme-count "ab")

2

> (string-grapheme-count "ab" 0 2)

2

> (string-grapheme-count "ab" 0 1)

1

> (string-grapheme-count "\\r\\n")

4

> (string-grapheme-count "a\\r\\nb")

6

Added in version 8.6.0.2.

6 Additional String Functions🔗

 (require racket/string) package: base
The bindings documented in this section are provided by the racket/string and racket libraries, but not racket/base.

procedure

(string-append* str ... strs) → string?

  str : string?
  strs : (listof string?)
类似于 string-append，但最后一个参数用作 string-append 的参数列表，因此 (string-append* str ... strs) 与 (apply string-append str ... strs) 相同。换句话说，string-append 和 string-append* 之间的关系类似于 list 和 list* 之间的关系。

Examples:
> (string-append* "a" "b" '("c" "d"))

"abcd"

> (string-append* (cdr (append* (map (lambda (x) (list ", " x))
                                     '("Alpha" "Beta" "Gamma")))))

"Alpha, Beta, Gamma"

procedure

(string-join strs    
  [sep    
  #:before-first before-first    
  #:before-last before-last    
  #:after-last after-last]) → string?
  strs : (listof string?)
  sep : string? = " "
  before-first : string? = ""
  before-last : string? = sep
  after-last : string? = ""
将 strs 中的字符串进行连接，在每对字符串之间插入 sep。before-last、before-first 和 after-last 类比 add-between 的输入：它们指定最后两个字符串之间的交替分隔符、前缀字符串和后缀字符串。

Examples:
> (string-join '("one" "two" "three" "four"))

"one two three four"

(string-trim str    
  [sep    
  #:left? left?    
  #:right? right?    
  #:repeat? repeat?]) → string?
  str : string?
  sep : (or/c string? regexp?) = #px"\\s+"

  right? : any/c = #t

"foo bar  baz \\r\\n\\t"

> (string-trim "aaaxaayaa" "aa")

The bindings documented in this section are provided by the racket/format and racket libraries, but not racket/base.

racket/format 库提供了将 Racket 值转换为字符串的函数。 除了填充和数字格式化等功能外，这些函数的优点是比 format（带格式字符串）、 number->string 或 string-append 更简短。

procedure

(~a v    
  ...    
  [#:separator separator    
  #:width width    
  #:max-width max-width    
  #:min-width min-width    
  #:limit-marker limit-marker    
  #:limit-prefix? limit-prefix?

  #:left-pad-string left-pad-string    
  #:right-pad-string right-pad-string]) → string?
  v : any/c
  separator : string? = ""
  width : (or/c exact-nonnegative-integer? #f) = #f
  max-width : (or/c exact-nonnegative-integer? +inf.0)
   = (or width +inf.0)
  min-width : exact-nonnegative-integer? = (or width 0)
  limit-marker : string? = ""
  limit-prefix? : boolean? = #f
  align : (or/c 'left 'center 'right) = 'left
  pad-string : non-empty-string? = " "
  left-pad-string : non-empty-string? = pad-string
  right-pad-string : non-empty-string? = pad-string
将每个 v 以 display 模式转换为字符串——即类似 (format "~a" v)——然后用 separator 连接连续项之间的结果，再将字符串填充或截断至至少 min-width 个字符、至多 max-width 个字符。

Examples:
> (~a "north")

"north"

> (~a 'south)

"south"

> (~a #"east")

"east"

> (~a #\w "e" 'st)

"west"

> (~a (list "red" 'green #"blue"))

"(red green blue)"

> (~a 17)

"17"

> (~a #e1e20)

"100000000000000000000"

> (~a pi)

"3.141592653589793"

> (~a (expt 6.1 87))

"2.1071509386211452e+68"

~a 函数主要适用于字符串、数字和其他原子数据。 ~v 和 ~s 函数更适合处理复合数据。

令 s 为 v 加上分隔符的连接字符串形式。如果 s 长度超过 max-width 个字符，则将其截断为恰好 max-width 个字符。如果 s 短于 min-width 个字符，则将其填充至恰好 min-width 个字符。否则 s 原样返回。如果 min-width 大于 max-width，则抛出异常。

如果 s 长度超过 max-width 个字符，则将其截断，并用 limit-marker 替换字符串末尾。如果 limit-marker 长于 max-width，则抛出异常。 如果 limit-prefix? 为 #t，则截断字符串开头而非末尾。

Examples:
> (~a "abcde" #:max-width 5)

"abcde"

> (~a "abcde" #:max-width 4)

"abcd"

> (~a "abcde" #:max-width 4 #:limit-marker "*")

"abc*"

> (~a "abcde" #:max-width 4 #:limit-marker "...")

"a..."

> (~a "The quick brown fox" #:max-width 15 #:limit-marker "")

"The quick brown"

> (~a "The quick brown fox" #:max-width 15 #:limit-marker "...")

"The quick br..."

> (~a "The quick brown fox" #:max-width 15 #:limit-marker "..." #:limit-prefix? #f)

"The quick br..."

如果 s 短于 min-width，则将其填充至至少 min-width 个字符。如果 align 为 'left，则只添加右侧填充；如果 align 为 'right，则只添加左侧填充；如果 align 为 'center，则添加大致相等的左右填充。

填充由非空字符串指定。左侧填充由 left-pad-string 尽可能多地完整重复，后跟 left-pad-string 的 前缀 来填充剩余空间。相反，右侧填充由 right-pad-string 的 后缀 后跟若干次 right-pad-string 完整副本组成。因此左侧填充以 left-pad-string 的开头开始，右侧填充以 right-pad-string 的结尾结束。

Examples:
> (~a "apple" #:min-width 20 #:align 'left)

"apple               "

> (~a "pear" #:min-width 20 #:align 'left #:right-pad-string " .")

"pear . . . . . . . ."

> (~a "plum" #:min-width 20 #:align 'right #:left-pad-string ". ")

". . . . . . . . plum"

> (~a "orange" #:min-width 20 #:align 'center
                #:left-pad-string "- " #:right-pad-string " -")

"- - - -orange- - - -"

使用 width 同时设置 max-width 和 min-width，确保结果字符串恰好为 width 个字符长：

> (~a "terse" #:width 6)

"terse "

> (~a "loquacious" #:width 6)

"loquac"

procedure

(~r x    
  [#:sign sign    
  #:base base    
  #:precision precision    
  #:notation notation    
  #:format-exponent format-exponent    
  #:min-width min-width    
  #:pad-string pad-string    
  #:groups groups    
  #:group-sep group-sep    
  #:decimal-sep decimal-sep]) → string?
  x : rational?
  sign : 
(or/c #f '+ '++ 'parens
      (let ([ind (or/c string? (list/c string? string?))])
        (list/c ind ind ind)))
   = #f
  base : (or/c (integer-in 2 36) (list/c 'up (integer-in 2 36)))
   = 10
  precision : 
(or/c exact-nonnegative-integer?
      (list/c '= exact-nonnegative-integer?))
 = 6
  notation : 
(or/c 'positional 'exponential
      (-> rational? (or/c 'positional 'exponential)))
   = 'positional
  format-exponent : (or/c #f string? (-> exact-integer? string?))
   = #f
  min-width : exact-positive-integer? = 1
  pad-string : non-empty-string? = " "
  groups : (non-empty-listof exact-positive-integer?) = '(3)
  group-sep : string? = ""
  decimal-sep : string? = "."
将有理数 x 转换为位置记数法或指数记数法的字符串，取决于 notation。x 的精确性或非精确性不影响其格式化。

可选参数控制数字格式化：

  • notation — 决定数字是以位置记数法还是指数记数法打印。如果 notation 是一个函数，则将其应用于 x 以获取要使用的记数法。

    Examples:
    > (~r 12345)

    "12345"

    > (~r 12345 #:notation 'exponential)

    "1.2345e+04"

    > (let ([pick-notation
             (lambda (x)
               (if (or (< (abs x) 0.001) (> (abs x) 1000))
                   'exponential
                   'positional))])
        (for/list ([i (in-range 1 5)])
          (~r (expt 17 i) #:notation pick-notation)))

    '("17" "289" "4.913e+03" "8.3521e+04")

  • precision — 控制小数点（或更准确地说，小数点）后的位数。当 x 以指数形式格式化时，precision 适用于有效数字。

    如果 precision 是一个自然数，则最多显示 precision 位数字，但会丢弃尾随零，如果小数点后所有数字都被丢弃，小数点也会被丢弃。如果 precision 是 (list '= digits)，则小数点后恰好使用 digits 位数字，小数点永远不会被丢弃。

    Examples:
    > (~r pi)

    "3.141593"

    > (~r pi #:precision 4)

    "3.1416"

    > (~r pi #:precision 0)

    "3"

    > (~r 1.5 #:precision 4)

    "1.5"

    > (~r 1.5 #:precision '(= 4))

    "1.5000"

    > (~r 50 #:precision 2)

    "50"

    > (~r 50 #:precision '(= 2))

    "50.00"

    > (~r 50 #:precision '(= 0))

    "50."

  • decimal-sep 指定打印的小数点分隔符。

    Examples:
    > (~r 123.456)

    "123.456"

    > (~r 123.456 #:decimal-sep ",")

    "123,456"

  • groups 控制数字整数部分的位数如何分组。 groups 最右边的数字用于分组整数部分最右边的位数。 groups 最左边的数字重复用于分组最左边的位数。 group-sep 参数指定数字组之间使用的分隔符。

    Examples:
    > (~r 1234567890 #:groups '(3) #:group-sep ",")

    "1,234,567,890"

    > (~r 1234567890 #:groups '(3 2) #:group-sep ",")

    "12,345,678,90"

    > (~r 1234567890 #:groups '(1 3 2) #:group-sep "_")

    "1_2_3_4_5_678_90"

  • min-width — 如果 x 通常打印时少于 min-width 位数字（包括小数点但不包括符号指示符），则使用 pad-string 对数字进行左侧填充。

    Examples:
    > (~r 17)

    "17"

    > (~r 17 #:min-width 4)

    "  17"

    > (~r -42 #:min-width 4)

    "-  42"

    > (~r 1.5 #:min-width 4)

    " 1.5"

    > (~r 1.5 #:precision 4 #:min-width 10)

    "       1.5"

    > (~r 1.5 #:precision '(= 4) #:min-width 10)

    "    1.5000"

    > (~r #e1e10 #:min-width 6)

    "10000000000"

  • pad-string — 指定用于将数字填充至至少 min-width 个字符（不包括符号指示符）的字符串。填充放置在符号与 x 的正常数字之间。

    Examples:
    > (~r 17 #:min-width 4 #:pad-string "0")

    "0017"

    > (~r -42 #:min-width 4 #:pad-string "0")

    "-0042"

  • sign — 控制数字符号的显示方式：

    • 如果 sign 为 #f（默认值），则当 x 为正数或零时不生成符号输出，当 x 为负数时添加负号前缀。

      Example:
      > (for/list ([x '(17 0 -42)]) (~r x))

      '("17" "0" "-42")

    • 如果 sign 为 '+，则当 x 为零时不生成符号输出，当 x 为正数时添加加号前缀，当 x 为负数时添加负号前缀。

      Example:
      > (for/list ([x '(17 0 -42)]) (~r x #:sign '+))

      '("+17" "0" "-42")

    • 如果 sign 为 '++，则当 x 为零或正数时添加加号前缀，当 x 为负数时添加负号前缀。

      Example:
      > (for/list ([x '(17 0 -42)]) (~r x #:sign '++))

      '("+17" "+0" "-42")

    • 如果 sign 为 'parens，则当 x 为零或正数时不生成符号输出，当 x 为负数时将数字括在括号中。

      Example:
      > (for/list ([x '(17 0 -42)]) (~r x #:sign 'parens))

      '("17" "0" "(42)")

    • 如果 sign 为 (list pos-ind zero-ind neg-ind)，则分别使用 pos-ind、zero-ind 和 neg-ind 来指示正数、零和负数。每个指示符要么是作为前缀使用的字符串，要么是包含两个字符串的列表：前缀和后缀。

      Example:
      > (let ([sign-table '(("" " up") "an even " ("" " down"))])
          (for/list ([x '(17 0 -42)]) (~r x #:sign sign-table)))

      '("17 up" "an even 0" "42 down")

      默认行为等效于 '("" "" "-")；'parens 模式等效于 '("" "" ("(" ")"))。

  • base — 控制 x 格式化的进制。如果 base 是大于 10 的数字，则使用小写字母。如果 base 是 (list 'up base*) 且 base* 大于 10，则使用大写字母。

    Examples:
    > (~r 100 #:base 7)

    "202"

    > (~r 4.5 #:base 2)

    "100.1"

    > (~r 3735928559 #:base 16)

    "deadbeef"

    > (~r 3735928559 #:base '(up 16))

    "DEADBEEF"

    > (~r 3735928559 #:base '(up 16) #:notation 'exponential)

    "D.EADBEF*16^+07"

  • format-exponent — 决定指数的显示方式。

    如果 format-exponent 是一个字符串，则指数显示带有显式符号（如同 sign 为 '++）且至少两位数字，通过"指数标记" format-exponent 与有效数字分隔：

    > (~r 1234 #:notation 'exponential #:format-exponent "E")

    "1.234E+03"

    如果 format-exponent 为 #f，则"指数标记"在 base 为 10 时为 "e"，否则为包含 base 的字符串：

    > (~r 1234 #:notation 'exponential)

    "1.234e+03"

    > (~r 1234 #:notation 'exponential #:base 8)

    "2.322*8^+03"

    如果 format-exponent 是一个 procedure，则将其应用于指数，并将结果字符串附加到有效数字之后：

    > (~r 1234 #:notation 'exponential
               #:format-exponent (lambda (e) (format "E~a" e)))

    "1.234E3"
