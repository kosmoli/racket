3 Identifiers🔗

Racket 的标识符语法特别宽松。排除特殊字符

(part "binding") (later in this guide) explains more about identifiers.

   ( ) [ ] { } " , ' ` ; # | \

以及构成数字常量的字符序列外，几乎任何非空白字符序列都构成 ‹id›。例如 substring 是一个标识符。同样，string-append 和 a+b 是标识符，而不是算术表达式。以下是更多示例：

+
integer?
pass/fail
Hfuhruhurr&Uumellmahaye
john-jacob-jingleheimer-schmidt
a-b-c+1-2-3
