gen:custom-write : any/c

一个 generic interface（参见 (part "struct-generics")），提供 一个 write-proc 方法，供默认打印机用于 display、 write 或 print 结构体类型的实例。

write-proc 方法接收三个参数：要打印的结构体、目标 port 和一个 参数——在 write 模式下为 #t，在 display 模式下 为 #f，或在 print 模式下为 0 或 1 以 表示当前的 quoting depth。procedure 应使用 write、 display、print、fprintf、write-special 等将值打印到给定的 port。

port write handler、port display handler 和 print handler 是为传给 custom-write procedure 的 port 特别配置的。 通过 display、write 或 print 向该 port 打印 会递归地打印 value 并带有 sharing 注解。为避免递归打印（即不考虑与当前正在打印的 value 的 sharing），改用字符串或 pipe 打印，然后使用 write-string 或 write-special 将结果传送到目标 port。要向 custom-write procedure 给定的 port 以外的 port 递归打印，请将给定 port 的 write handler、display handler 和 print handler 复制到其他 port。

传给 write-proc 的 port 不一定是实际的目标 port。具体来说，为了检测 cycle、sharing 和引用模式（在 print 模式下），打印机使用一个记录 递归打印信息的 port 调用 custom-write procedure，不会保留任何其他输出。这个 信息收集阶段需要打印相同的对象（在 eq? 意义上），以便记录的 信息可以与打印的值相关联。

递归打印操作可能会触发从 write-proc 调用中退出。例如，在 pretty-printing 过程中，当一次初步的打印尝试超出行宽时可能会退出；或者在受限宽度的错误输出打印时 也可能退出。

以下是一个 tuple 类型的示例定义，它包含一个 write-proc procedure， 在 write 和 print 模式下使用尖括号打印 tuple 的 list 内容， 在 display 模式下不使用括号。tuple 的元素会被递归打印，以便能够 表示 graph 和 cycle 结构。

Examples:
(define (tuple-print tuple port mode)
  (when mode (write-string "<" port))
  (let ([l (tuple-ref tuple)]
        [recur (case mode
                 [(#t) write]
                 [(#f) display]
                 [else (lambda (p port) (print p port mode))])])
     (unless (zero? (vector-length l))
       (recur (vector-ref l 0) port)
       (for-each (lambda (e)
                   (write-string ", " port)
                   (recur e port))
                 (cdr (vector->list l)))))
  (when mode (write-string ">" port)))

 

(struct tuple (ref)
        #:methods gen:custom-write
        [(define write-proc tuple-print)])

 

> (display (tuple #(1 2 "a")))

1, 2, a

> (print (tuple #(1 2 "a")))

<1, 2, "a">

> (let ([t (tuple (vector 1 2 "a"))])
    (vector-set! (tuple-ref t) 0 t)
    (write t))

#0=<#0#, 2, "a">

make-constructor-style-printer 函数可以帮助实现 write-proc， 如本例所示：

Examples:
(require racket/struct)

 

(struct point (x y)
  #:methods gen:custom-write
  [(define write-proc
     (make-constructor-style-printer
      (lambda (obj) 'point)
      (lambda (obj) (list (point-x obj) (point-y obj)))))])

 

> (print (point 1 2))

(point 1 2)

> (write (point 1 2))

#<point: 1 2>

Changed in version 8.7.0.5: 添加了检查，使得省略 write-proc 现在是语法错误。

prop:custom-write : struct-type-property?

一个 structure type property（参见 (part "structprops")），提供一个 与 gen:custom-write 的 write-proc 对应的 procedure。 不鼓励使用 prop:custom-write property；应改用 gen:custom-write generic interface。

procedure

(custom-write? v) → boolean?

  v : any/c
如果 v 具有 prop:custom-write property 则返回 #t， 否则返回 #f。

procedure

(custom-write-accessor v)

 → (custom-write? output-port? (or/c #t #f 0 1) . -> . any)
  v : custom-write?
返回与 v 关联的 custom-write procedure。

prop:custom-print-quotable : struct-type-property?

value

custom-print-quotable? : struct-type-property?

value

custom-print-quotable-accessor : struct-type-property?

一个 property 以及关联的 predicate 和 accessor。该 property value 是 'self、'never、'maybe 或 'always 之一。当结构体除了 prop:custom-write property value 之外还具有此 property 时， 该 property value 会影响 print 模式下的打印；参见 (part "printing")。 当 value 不具有 prop:custom-print-quotable 时，其效果等同于具有 'self property value，这既适用于自引用形式，也适用于不可读的 打印形式。
