求值和运行模块 (CS)

racket_apply 函数提供基本的求值支持， 但 racket_eval、racket_dynamic_require 和 racket_namespace_require 为初始化 Racket 实例时的 最常见求值任务提供了更高级的支持。

ptr

 

racket_eval

(

ptr s_expr)

在初始 Racket 线程中使用其当前的 namespace 对 s_expr 进行求值， 与调用 eval 相同。s_expr 可以是通过 pair、symbol 等 构建的 S-expression，也可以是一个 syntax object。

使用 racket_namespace_require 来初始化 namespace，或使用 racket_dynamic_require 来访问功能而无需进入顶层 namespace。 尽管这些函数与使用 namespace-require 和 dynamic-require 相同， 但它们在 namespace 中未预先绑定这些标识符的情况下也能工作。

本节中的函数并非旨在从 Racket 调用的 C 代码中调用。 另请参阅 (part "cs-procs") 中关于 入口点 与 重入口点的讨论。
