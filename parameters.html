Parameters🔗

(part ("(lib scribblings/guide/guide.scrbl)" "parameterize")) in (part ("(lib scribblings/guide/guide.scrbl)" "top")) introduces parameters.

参见 (part "parameter-model") 了解 parameter 模型的基本信息。Parameters 对应于 Scsh [Gasbichler02] 中的 preserved thread fluids。

要以线程和 continuation 友好的方式参数化代码，请使用 parameterize。parameterize form 为其 body 表达式的 dynamic extent 引入一个新的 thread cell。

创建新线程时，新线程的初始 continuation 的 parameterization 是创建者线程的 parameterization。由于每个 parameter 的 thread cell 是 preserved 的，新线程"继承"其创建线程的 parameter 值。当 continuation 从一个线程移动到另一个线程时，使用 parameterize 引入的设置会有效地随 continuation 一起移动。

相反，直接赋值给 parameter（通过调用 parameter 过程并传入一个值）会更改 thread cell 中的值，因此仅更改当前线程的设置。因此，就内存管理器而言，只要 continuation 可达，通过 parameterize 与 parameter 关联的原始值仍然保持可达，即使该 parameter 被 mutate。

procedure

(make-parameter v [guard name realm]) → parameter?

  v : any/c
  guard : (or/c (any/c . -> . any) #f) = #f
  name : symbol? = 'parameter-procedure
  realm : symbol? = 'racket
返回一个新的 parameter 过程。该 parameter 的值在所有线程中初始化为 v。

如果 guard 不是 #f，则它用作 parameter 的 guard 过程。guard 过程接受一个 argument。每当 parameter 过程应用于一个 argument 时，该 argument 被传递给 guard 过程。guard 过程返回的结果用作新的 parameter 值。guard 过程可以引发异常以拒绝 parameter 值的更改。guard 不应用于初始 v。

name 参数用作 object-name 报告的 parameter 过程名称，realm 用作 procedure-realm 报告的 parameter 过程 realm。

Changed in version 7.4.0.6: 添加了 name 参数。
Changed in version 8.4.0.2: 添加了 realm 参数。

syntax

(parameterize ([parameter-expr value-expr] ...)
  body ...+)
 
  parameter-expr : parameter?

(part ("(lib scribblings/guide/guide.scrbl)" "parameterize")) in (part ("(lib scribblings/guide/guide.scrbl)" "top")) introduces parameterize.

parameterize 表达式的结果是最后一个 body 的结果。parameter-expr 确定要设置的 parameters，value-expr 确定在求值 body 时要安装的相应值。parameter-expr 和 value-expr 从左到右（交错）求值，然后在 continuation 中将 parameter 绑定到包含 value-expr 值的 preserved thread cells；每个 parameter-expr 的结果在绑定前用 parameter? 检查。最后一个 body 相对于整个 parameterize form 处于 tail 位置。

在 parameterize 表达式的 dynamic extent 之外，parameters 保持绑定到其他 thread cells。因此，当控制退出 parameterize 表达式时，旧的 parameter 设置会被恢复。

如果在 parameterize 求值期间捕获了 continuation，调用 continuation 会有效地重新引入 parameterization，因为 parameterization 通过 continuation mark（参见 (part "contmarks")）使用私有 key 与 continuation 关联。

Examples:
> (parameterize ([exit-handler (lambda (x) 'no-exit)])
    (exit))
> (define p1 (make-parameter 1))
> (define p2 (make-parameter 2))
> (parameterize ([p1 3]
                 [p2 (p1)])
    (cons (p1) (p2)))

'(3 . 1)

> (let ([k (let/cc out
             (parameterize ([p1 2])
               (p1 3)
               (cons (let/cc k
                       (out k))
                     (p1))))])
    (if (procedure? k)
        (k (p1))
        k))

'(1 . 3)

> (define ch (make-channel))
> (parameterize ([p1 0])
    (thread (lambda ()
              (channel-put ch (cons (p1) (p2))))))

#<thread>

> (channel-get ch)

'(0 . 2)

> (define k-ch (make-channel))
> (define (send-k)
    (parameterize ([p1 0])
      (thread (lambda ()
                (let/ec esc
                  (channel-put ch
                               ((let/cc k
                                  (channel-put k-ch k)
                                  (esc)))))))))
> (send-k)

#<thread>

> (thread (lambda () ((channel-get k-ch)
                      (let ([v (p1)])
                        (lambda () v)))))

#<thread>

> (channel-get ch)

1

> (send-k)

#<thread>

> (thread (lambda () ((channel-get k-ch) p1)))

syntax

(parameterize* ((parameter-expr value-expr) ...)
  body ...+)
类似于 let* 相比于 let，parameterize* 等同于嵌套的单 parameter parameterize form。

procedure

(make-derived-parameter parameter    
  guard    
  wrap    
  [name    
  realm]) → parameter?
  parameter : parameter?
  guard : (any/c . -> . any)
  wrap : (any/c . -> . any)
  name : symbol? = (object-name parameter)
  realm : symbol? = (procedure-realm parameter)
返回一个 parameter 过程，设置或检索与 parameter 相同的值，但带有：

  • 设置 parameter 时应用 guard（在 parameter 关联的任何 guard 之前），以及

  • 获取 parameter 值时应用 wrap。

name 参数用作 object-name 报告的 parameter 过程名称，realm 用作 procedure-realm 报告的 parameter 过程 realm。如果目标是仅替换 parameter 的名称或 realm，则为 guard 和 wrap 提供 values。

另请参见 chaperone-procedure，它也可用于保护 parameter 过程。

Changed in version 8.15.0.4: 添加了 name 和 realm 参数。

procedure

(parameter? v) → boolean?

  v : any/c
如果 v 是 parameter 过程，则返回 #t，否则返回 #f。

procedure

(parameter-procedure=? a b) → boolean?

  a : parameter?
  b : parameter?
如果 parameter 过程 a 和 b 始终使用相同的 guard 修改相同的 parameter（尽管可能使用不同的 chaperones），则返回 #t，否则返回 #f。

procedure

(current-parameterization) → parameterization?

返回当前 continuation 的 parameterization。

procedure

(call-with-parameterization parameterization    
  thunk) → any
  parameterization : parameterization?
  thunk : (-> any)
以 parameterization 作为当前 parameterization（通过 tail 调用）调用 thunk。

procedure

(parameterization? v) → boolean?

  v : any/c
如果 v 是 current-parameterization 返回的 parameterization，则返回 #t，否则返回 #f。
